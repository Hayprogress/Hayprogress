Grammar Rule Quick Reference
  • Auxiliary Verb (Present): եմ, ես, է, ենք, եք, են | Negative: չեմ, չես, չի, չենք, չեք, չեն
  • Present Tense: Verb stem + ում + Auxiliary (e.g., կարդում եմ / չեմ կարդում)
  • Past Participle (-ել): Verb stem + ել + Auxiliary (e.g., ապրել եմ / չեմ ապրել)
  • Past Participle (-ալ): Verb stem + ացել + Auxiliary (e.g., կարդացել եմ / չեմ կարդացել)
  • Future Tense: Infinitive + ու + Auxiliary (e.g., գրելու եմ / չեմ գրելու)
